Mudança para o Império

Lendo os dados deste aparelho…

1Guarde uma cópia de segurança

Salva um arquivo com todas as suas notas e abas. Escolha “Salvar em Arquivos”. Nada é apagado daqui.

2Copie os dados

Coloca tudo na área de transferência, pronto para colar no Império.

3Cole no Império

Abra o Cofre de Notas no Império, entre com a senha do cofre e toque em “Colar dados copiados”. As imagens das notas passam a ficar no cofre privado.

Abrir o Cofre de Notas no Império

Esta página só lê os dados deste aparelho e não envia nada para lugar nenhum: a cópia vai para o seu arquivo e para a área de transferência.
